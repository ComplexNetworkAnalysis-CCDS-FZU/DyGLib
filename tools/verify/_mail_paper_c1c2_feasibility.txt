一、**结论：可行**，工程成本 ≈ **0.5–1 个工作日（含单测）**；跑数 ≈ **1–2 h GPU**（30 runs）；取数/回报 ≈ 0.5 h。**唯一卡点 = 仓库归属**（repro 仓库属 Baseline 工作区，需授权方案，见四）。

二、**已核代码事实（只读检查，`train_eval/dysdgnn.py`，与 b786 记录一致）**
- `_prep()`：每 clip k 的嵌入依赖 ①本 clip 全部边的 motif 邻居（含目标边自身）②节点活跃集 ③MT-SA 序列 = `active_clips[node][:searchsorted(al, k, side="right")]`——**side="right" 含 k 本身**（即当前 clip 自身参与自己的嵌入）；
- `_eval_split()`：对 split 的每个 clip k 取 `p = mtsa_at(z_stack, clips, k)` 后直接用刚算出的嵌入打分该 clip 的边 ⇒ **C0 = 目标边参与自身嵌入**（转导可见性，已确认）。
- ⇒ 两条改动路径：
  - **C2-approx（前窗为界）**：MT-SA 改 `side="left"`（1 行）+ 邻居列表限于 <k 的 clip（`_prep` 加一个 mask 变体）→ 便宜；
  - **C1-approx（测试边全掩蔽）**：把 test split 的边从嵌入图剔除。

三、**关键技术发现（需与 587/129c 口径对齐）**：在本快照设计下（等宽窗、测试 = 最后若干完整窗），**"测试边全掩蔽"与"前窗为界"两档会合并为同一件事**（都等价于"test 嵌入只看过去窗"）。若要保留真正的两级阶梯，**C1 必须做逐边精确掩蔽**（每目标边一次重算前向）。成本估算：每 ds 测试边 ≈ 3–5k，逐边前向 ~10–50 ms → 每 run +2–5 min，30 runs ≈ 1–2.5 h GPU——**仍可行**。若不接受合并，建议口径改为："C1 = 逐边精确（mask-self）；C2 = 严格过去（逐边滚动，含当前窗剔除）"，近似档作为兜底并在 JSON 里声明。
