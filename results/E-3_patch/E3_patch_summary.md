## 结论（供 A 引用）

1. **P=1（默认）为最优或持平最优**：RedditBody 上 AUC 从 P1 的 0.9610 单调降至 P7 的 0.9400（-0.021）；WikiVote 上各 P 几乎持平（AUC 差 ≤ 0.0008）。
2. **大 patch 有损、无益**：patch 增大降低时间分辨率，RedditBody 受明显影响（所有指标一致下降），WikiVote 基本不敏感。
3. **回应审稿 R2#8 的 patch 超参分析**：保持默认 patch_size=1 有据可依；无需改动模型。可作为 patch size 影响的热图/表引用，说明 SignDyG 在 patch 选择上稳健且默认值最优。
4. 与 CPU 期对照（若 A 需 CPU↔GPU 一致性佐证）：本表为 GPU 基座最终口径。
