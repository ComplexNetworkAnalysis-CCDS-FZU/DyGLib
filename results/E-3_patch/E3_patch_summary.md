## 结论（供 Paper 引用）

1. **patch size 在修复口径下不敏感**：RedditBody 各 P 的 AUC 波动区间 0.9149–0.9284（跨度 0.0135，无单调趋势；P7 的 AUC/AP 略高、P1 的 Sign-F1 最高）；WikiVote 几乎持平（AUC 跨度 0.0025）。单种子，差异量级与种子波动相当。
2. **默认 patch_size=1 有据可依**（回应 R2#8）：扩大 patch 未带来一致收益，保持默认即可；模型对 patch 选择稳健。可作为 patch size 影响表的引用。
3. ⚠️ **表述更新提醒**：旧版（伪交集）曾显示 RedditBody“P1→P7 单调下降（−0.021）”；CN 修复后该趋势**未复现**——论文/回复信中相关文字请以本表（修复版）为准。
4. 设备：统一 GPU 基座；结果 JSON 含 `device` 字段可核验。
